# Banking REST API

## Project Overview
A Banking REST API developed using Java
and Spring Boot.

## Technologies Used
- Java
- Spring Boot
- Maven
- REST API

## Features
- Account Management
- Create Bank Accounts
- Retrieve Account Details
- RESTful API Architecture

## How to Run
1. Clone the repository.
2. Open the project in VS Code.
3. Run the BankingApiApplication.java file.
4. Access the API using Postman.
